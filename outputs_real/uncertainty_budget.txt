What this cannot show:
  - that this is a Bayesian credible interval: a credible interval is a posterior quantile, a posterior needs a likelihood, and this repository holds ZERO engine-output/patient-outcome pairs to build one from. The interval here is the empirical spread of a measured input propagated through the engine, with coverage over (donor, seed) jointly
  - that MGMT beta is the only uncertainty in the prediction: it is the one input this repository can measure per donor, and the engine's rate constants remain declared assumptions, so the input channel measured here is a lower bound on the true input uncertainty
  - that a band from donor tumours bounds the error for a NEW patient: the one-beta-per-case contract is a cohort distribution applied to a case
  - that the mapping beta -> r0 is right: it is a declared convention anchored on the calibrated default, and a different anchor moves every number in the band without any code changing
  - that the trial design is fixed: the switching arm saturates at the horizon, so its PFS readout has no spread to decompose and the conclusion drawn from it is about THIS design, not the policy family
